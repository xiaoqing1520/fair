# FIGN 公平点火台

🚀 公平 · 透明 · 逻辑清晰，开启 WEB3 新征程！

## 项目简介

FIGN 公平点火台是一个去中心化的代币发射平台，致力于打造最透明、最公平的代币发行机制。

## 核心特性

- ✅ **公平透明** - 智能合约执行，公开可查
- ✅ **自动化机制** - 自动分配，自动加池
- ✅ **人人可参与** - 公开 Mint，零门槛参与
- ✅ **链上公开** - 安全透明，人人可验证

## 如何参与 MINT

1. 连接你的 Web3 钱包（MetaMask / Trust Wallet）
2. 确保钱包中有至少 0.02 BNB + Gas 费
3. 点击"立即 MINT"按钮
4. 确认交易，等待区块确认
5. 自动获得 FIGN 代币！

## 资金分配

- 💧 50% 自动加池（流动性池）
- 🎁 50% 用于 MINT（用户奖励）

## 部署

### 使用 GitHub Pages

1. 上传所有文件到 GitHub 仓库
2. 进入仓库设置 (Settings)
3. 找到 Pages 选项
4. 选择 main 分支
5. 保存，等待部署完成

### 使用 Vercel

1. 导入 GitHub 仓库到 Vercel
2. 点击 Deploy
3. 自动部署完成
